How this is deployed

1 · Host the demos

This folder is a static site. Push it to GitHub, then connect the repo to Netlify (or Cloudflare Pages) — build command empty, publish directory .. Every card opens its dashboard in a new tab.

2 · Install a real client

Copy Code.gs, SeedData.gs and Index.html into a Google Sheet's Apps Script editor, run the seeder once, then deploy as a web app.

3 · Swap the data

Headings, tab names and the currency all live in SETTINGS. Point it at the client's own tabs and the same dashboard starts reporting their numbers.
